# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

ShopProject — учебный интернет-магазин компьютерной периферии: мыши,
клавиатуры и гарнитуры.

## Структура проекта

- `index.html` — главная страница с hero-каруселью, преимуществами,
  популярными товарами и отзывами;
- `catalog.html` — каталог товаров с фильтрами по категории и цене;
- `product.html` — детальная страница товара с таблицей характеристик;
- `contacts.html` — контактная информация;
- `order.html` — форма оформления заявки с проверкой в браузере;
- `css/style.css` — файл стилей проекта;
- `js/main.js` — интерактивность (меню, карусель, диалог, фильтры);
- `images/` — изображения товаров и главной страницы;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка, нативный `<dialog>`);
- CSS3 (Flexbox, Grid, собственные медиа-запросы для адаптивности);
- JavaScript (ES6+, без внешних библиотек);
- Git, GitHub.

Внешние CSS/JS-фреймворки (Bootstrap и аналоги) не используются: сетки,
кнопки, карточки, навигация, карусель, модальное окно и уведомления
реализованы вручную. Адаптивность обеспечивается медиа-запросами в
разделе «Адаптивность» файла `css/style.css` (контрольные точки:
1024, 900, 768 и 576 пикселей).
